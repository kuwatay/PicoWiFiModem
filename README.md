# PicoWiFiModem Retro EditionA retro computer oriented fork of PicoWiFiModem for Raspberry Pi Pico W.This branch focuses on Z80/CP/M style systems and retro serial computing environments using a simple TTL serial connection and Hayes compatible AT commands.Branch name:```text id="hhm4xl"PicoWiFiModem-Retro-Edition```Based on:* PicoWiFiModem by mecparts* Raspberry Pi Pico W* lwIP / cyw43 WiFi stack---# Features* Hayes compatible AT command modem* Telnet/BBS access over WiFi* Retro computer compatible UART interface* Internal flash configuration storage* No external EEPROM required* No RS-232 level shifter required* UART0 fixed on GP0/GP1* WiFi / Link / TX / RX status LEDs* Tested with CP/M terminal software and BBS systems---# Hardware## Required* Raspberry Pi Pico W* Retro computer with TTL serial interface* USB serial adapter for initial testing (optional)## UART Pins| Pico W | Function || ------ | -------- || GP0    | UART0 TX || GP1    | UART0 RX |## LED Pins| Pico W | Function || ------ | -------- || GP10   | WIFI LED || GP11   | LINK LED || GP12   | TX LED   || GP13   | RX LED   |LED wiring:```text id="4zw6rr"GP10 -> 1k -> LED -> GND   WIFIGP11 -> 1k -> LED -> GND   LINKGP12 -> 1k -> LED -> GND   TXGP13 -> 1k -> LED -> GND   RX```## Optional Modem Control PinsThe original modem control signals are still supported for compatibility.| Pico W | Signal || ------ | ------ || GP2    | RTS    || GP3    | CTS    || GP4    | DCD    || GP5    | DSR    || GP6    | DTR    || GP7    | RI     |These pins may remain unconnected.---# Minimal Serial Wiring| System | Pico W || ------ | ------ || TX     | GP1 RX || RX     | GP0 TX || GND    | GND    |For 5V systems, level conversion is recommended on RX input.Recommended divider:```text id="vzwu4m"5V TX -> 10k -> Pico RX               |              20k               |              GND```---# FTDI TestingBefore connecting to a retro computer, testing with a 3.3V FTDI adapter is recommended.| FTDI | Pico W || ---- | ------ || TX   | GP1 RX || RX   | GP0 TX || GND  | GND    |Serial settings:* 9600 or 115200 baud* 8N1* No flow control---# Build## macOSInstall tools:```bash id="8r4y6g"brew install cmake ninjabrew install --cask gcc-arm-embedded```Clone Pico SDK:```bash id="4djz3l"mkdir -p ~/picocd ~/picogit clone --recurse-submodules https://github.com/raspberrypi/pico-sdk.gitexport PICO_SDK_PATH=$HOME/pico/pico-sdk```Clone project:```bash id="x6dx31"git clone https://github.com/YOURNAME/PicoWiFiModem.gitcd PicoWiFiModem/src```Build:```bash id="96lz5o"mkdir buildcd buildcmake .. -G Ninja -DPICO_BOARD=pico_wninja```Generated UF2:```text id="6qezd6"wifi_modem.uf2```---# Flashing1. Hold BOOTSEL on Pico W2. Connect USB3. Copy UF2 to RPI-RP2 drive4. Pico W reboots automatically---# ConfigurationExample setup:```text id="v6vd66"ATAT$SSID=your_ssidAT$PASS=your_passwordAT&WATC1```Connect to a BBS:```text id="3ozryq"ATDT towel.blinkenlights.nl:23```Display settings:```text id="9h5j0u"AT&V0```---# Flash Configuration StorageThis fork stores modem configuration in the last 4KB flash sector of the Pico W.No external EEPROM is required.Configuration is saved using:```text id="0g6d2q"AT&W```---# Notes* RTS/CTS flow control is optional* Modem control signals may remain unconnected* Recommended initial speeds:  * 9600  * 19200  * 38400---# LicenseThis project is based on PicoWiFiModem by mecparts.The original project is licensed under the GNU General Public License v3.0 (GPL-3.0).This fork and all modifications are therefore also distributed under the terms of the GNU GPL v3.0.See:* LICENSE* COPYING* Original PicoWiFiModem repositoryfor full license details.
